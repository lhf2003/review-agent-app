## 一、重构概述

### 1.1 重构目标
- 修改答题逻辑从"立即提交"改为"延迟提交"
- 用户可以自由重新选择答案，直到点击"提交答案"按钮
- 在最后一题显示"提交答案"按钮
- 提交后显示解析内容，禁止修改

### 1.2 重构内容
#### 修改的文件
1. **frontend/src/pages/QuizPage.vue**
   - 添加本地答案存储（`answersMap`）
   - 添加全部提交状态（`isAllSubmitted`）
   - 修改 `handleQuestionAnswer` 仅存储本地答案
   - 新增 `submitAllAnswers` 方法统一提交
   - 修改 `loadQuestionState` 支持本地答案加载
   - 修改 `handleResetQuiz` 清空本地状态
   - 添加"提交答案"按钮和"已完成"徽章

#### 验证的文件（无需修改）
2. **frontend/src/components/quiz/SingleChoiceQuestion.vue**
   - 已支持 `isSubmitted` 控制
   - 允许在未提交时重新选择

3. **frontend/src/components/quiz/MultipleChoiceQuestion.vue**
   - 已支持 `isSubmitted` 控制
   - 允许在未提交时重新选择

4. **frontend/src/components/quiz/TrueFalseQuestion.vue**
   - 已支持 `isSubmitted` 控制
   - 允许在未提交时重新选择

5. **frontend/src/components/quiz/FillBlankQuestion.vue**
   - 已支持 `isSubmitted` 控制
   - 允许在未提交时修改

## 二、测试场景

### 2.1 场景1：单选题重新选择
**步骤**：
1. 进入答题页面
2. 选择单选题的选项 A
3. 再次点击选项 B
4. 切换到下一题，再返回

**预期结果**：
- 步骤2：答案更新为 A，但不提交到后端
- 步骤3：答案从 A 变为 B，覆盖之前的答案
- 步骤4：返回后，答案仍为 B

### 2.2 场景2：多选题重新选择
**步骤**：
1. 进入多选题
2. 依次选择 A、B、D
3. 取消选择 B
4. 添加选择 C

**预期结果**：
- 步骤2：选中 A、B、D，答案为 "A,B,D"
- 步骤3：取消 B，答案变为 "A,D"
- 步骤4：添加 C，答案变为 "A,C,D"

### 2.3 场景3：判断题重新选择
**步骤**：
1. 进入判断题
2. 点击"是"
3. 点击"否"

**预期结果**：
- 步骤2：答案为 "true"
- 步骤3：答案变为 "false"

### 2.4 场景4：填空题修改答案
**步骤**：
1. 进入填空题
2. 填写第一个空为"答案1"
3. 修改为"答案1修改"

**预期结果**：
- 步骤2：第一个空为"答案1"
- 步骤3：第一个空变为"答案1修改"

### 2.5 场景5：跨题目答案保持
**步骤**：
1. 第1题选择答案 A
2. 切换到第2题，选择答案 B
3. 返回第1题

**预期结果**：
- 步骤3：第1题答案仍为 A

### 2.6 场景6：提交答案（全部已完成）
**步骤**：
1. 完成所有题目的答案选择
2. 切换到最后一题
3. 点击"提交答案"按钮
4. 查看解析内容

**预期结果**：
- 步骤2：显示"提交答案"按钮（绿色）
- 步骤3：显示"正在提交答案..."消息
- 步骤3：提交成功后显示"答案已提交"消息
- 步骤3：按钮消失，显示"已完成答题"徽章
- 步骤4：所有题目显示解析，禁止修改

### 2.7 场景7：提交答案（有未作答题目）
**步骤**：
1. 完成部分题目（例如：第1、3、5题，未作答第2、4题）
2. 切换到最后一题
3. 点击"提交答案"按钮
4. 查看提示对话框

**预期结果**：
- 步骤2：显示"提交答案"按钮（绿色）
- 步骤3：弹出确认对话框
- 步骤4：对话框显示"第 2、4 题还没有作答，确定要提交吗？"
- 步骤4：对话框有两个按钮：
  - "确定提交"（右侧，主按钮）
  - "继续答题"（左侧，次按钮）
- 步骤4-1：点击"继续答题"，对话框关闭，返回答题页面，未提交
- 步骤4-2：点击"确定提交"，继续提交流程

### 2.8 场景8：提交后禁止修改
**步骤**：
1. 提交所有答案
2. 尝试点击任何选项

**预期结果**：
- 所有选项不可点击
- 鼠标悬停时显示为不可用状态

### 2.9 场景9：重置测验
**步骤**：
1. 完成部分题目
2. 点击"重新开始"按钮
3. 确认重置

**预期结果**：
- 步骤2：弹出确认对话框
- 步骤3：所有答案清空，回到第1题

## 四、API 验证

### 4.1 提交接口调用
- 接口：`POST /collection/submit-answer`
- 调用时机：点击"提交答案"按钮后
- 调用次数：等于已答题目的数量
- 请求体：
  ```json
  {
    "questionId": 123,
    "userAnswer": "A" 或 "A,B,D" 或 "true" 或 "答案1,答案2"
  }
  ```

### 4.2 错误处理
- 网络错误：显示"提交答案失败，请重试"
- 未提交状态：不调用接口
