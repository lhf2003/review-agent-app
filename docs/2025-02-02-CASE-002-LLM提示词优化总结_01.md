# LLM提示词优化总结

**创建日期**: 2025-02-02
**作者**: Claude Code
**版本**: v1.0
**状态**: 已完成

## 一、优化背景

### 1.1 原有问题
1. **硬编码提示词**：QuizService 中直接硬编码了提示词，不利于维护和优化
2. **格式稳定性差**：LLM 返回格式不稳定，偶尔包含 Markdown 代码块标记
3. **题目质量不一致**：缺乏明确的质量标准和设计指南
4. **缺乏详细说明**：提示词对题型、难度、知识点等要求不够详细
5. **示例不足**：缺少具体的示例帮助 LLM 理解要求

### 1.2 优化目标
1. 将提示词抽离到独立的配置文件
2. 提供详细的题型说明和质量标准
3. 增强提示词的结构化和可读性
4. 提供具体的示例和模板
5. 提高 LLM 返回格式的稳定性

### 2.2 提示词优化要点

#### 2.2.1 结构化角色定义
```markdown
## Role: AI习题生成专家
### Profile
- language: 中文
- description: 专业编程教育专家
### Background
说明习题生成的重要性和价值
### Goal
明确生成 3-8 道高质量题目的目标
```

#### 2.2.2 详细的题型说明
每种题型都包含：
- **适用场景**：什么情况下使用该题型
- **具体要求**：设计题目的具体标准
- **示例**：完整的题目示例

例如，单选题：
```markdown
#### 1. 单选题 (single_choice)
**适用场景**：测试基本概念、原理理解、API用法
**要求**：
- 提供 4 个选项（A、B、C、D）
- 只有一个正确答案
- 干扰项要有一定的迷惑性
- 避免使用"以上都对"、"以上都错"等模糊选项
```

#### 2.2.3 明确的质量标准
从三个维度定义质量：
1. **题目质量标准**：准确性、清晰性、针对性、层次性、实用性、完整性
2. **选项设计标准**：干扰性、互斥性、完整性、长度均衡
3. **解析撰写标准**：全面性、深入性、实用性、拓展性

#### 2.2.4 五级难度体系
```
难度1（很简单）：直接记忆类题目
难度2（简单）：单一知识点应用
难度3（中等）：多个知识点综合
难度4（困难）：复杂场景应用
难度5（很困难）：综合能力测试
```

#### 2.2.5 知识点命名规范
```
格式：技术领域 + 具体概念
示例：
- "Java数据类型"
- "Spring依赖注入"
- "React状态管理"
```

#### 2.2.6 强化的格式约束
在多处强调输出格式要求：
- Constraints 部分：明确要求"仅返回 JSON 数组"
- OutputFormat 部分：详细说明 JSON 结构
- FinalReminder 部分：三次强调"绝对不要"添加额外内容

```markdown
### FinalReminder
- **绝对不要**在 JSON 外添加任何说明性文字
- **绝对不要**使用 Markdown 代码块标记（如 ```json）
- **绝对不要**输出"好的"、"明白了"等对话性内容
- **只输出纯 JSON 数组**，从 `[` 开始，到 `]` 结束
- 确保 JSON 格式完全正确，可以被直接解析
```

#### 2.2.7 具体的示例
提供完整的示例输入和输出，帮助 LLM 理解要求：

**示例输入**（使用模板变量）：
```markdown
### ExampleInput
${cases}
```

**示例输出**：
```json
[
  {
    "question": "在案例1中，用户遇到的空指针异常是因为？",
    "type": "single_choice",
    "options": [...],
    "answer": "B",
    "explanation": "详细解析...",
    "knowledgePoint": "Java异常处理",
    "difficulty": 2,
    "timeLimit": 45,
    "relatedCaseIndex": 1
  }
]
```

#### 2.3.2 添加 Quiz 前缀处理
```java
private String buildPromptName(String fileName, String promptName) {
    if (fileName.contains("Analysis")) {
        return "Analysis." + promptName;
    } else if (fileName.contains("Classify")) {
        return "Classify." + promptName;
    } else if (fileName.contains("Extract")) {
        return "Extract." + promptName;
    } else if (fileName.contains("Report")) {
        return "Report." + promptName;
    } else if (fileName.contains("Chat")) {
        return "Chat." + promptName;
    } else if (fileName.contains("Quiz")) {  // 新增
        return "Quiz." + promptName;
    }
    return promptName;
}
```

#### 2.3.3 添加公共方法
```java
/**
 * 获取习题生成提示词
 */
public String getQuizGenerationPrompt(String cases) throws PromptProcessingException {
    Map<String, Object> variables = new HashMap<>();
    variables.put("cases", cases);
    return buildPrompt("Quiz.习题生成提示词", variables);
}
```
