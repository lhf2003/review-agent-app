# AI 学习辅导功能开发计划

根据您的要求，我制定了以下分阶段实施计划。当前处于 **第一阶段：需求分析与初步构想**。请您审核以下方案，确认无误后我们将进入数据库设计阶段。

## 1. 需求分析与初步构想 (待确认)

**核心目标**：利用 LLM 分析合集内的“代码问题”和“根因”，生成定制化的测验题，帮助用户巩固知识，避免重复犯错。

**功能模块设计**：

1. **智能出题 (Quiz Generation)**：

   * **输入**：用户选择一个“合集”（包含若干个 `AnalysisResult`）。

   * **处理**：后端提取合集中所有 `problemStatement`（问题描述）和 `solution`（解决方案/根因）。

   * **AI 动作**：Prompt 提示词将要求 LLM 基于这些真实案例生成单选题（包含题干、选项、正确答案、解析）。

   * **输出**：一组结构化的题目。
2. **学习会话管理 (Session Management)**：

   * 记录每次学习的开始时间、结束时间、得分。

   * 支持“查看历史测验”功能，避免重复生成消耗 Token。
3. **交互式答题 (Interactive UI)**：

   * 复用并增强现有的 `CollectionDetailPage.vue` 中的抽屉组件。

   * 实时反馈：用户选择选项后，立即显示正确/错误及解析。

**API 接口预览**：

* `POST /quiz/generate?collectionId={id}`: 生成或获取该合集的今日测验。

* `POST /quiz/submit`: 提交答题结果（可选，用于统计错题率）。

* `GET /quiz/history`: 查看历史学习记录。

***

## 2. 数据库设计预案 (待执行)

基于 `init.sql`，建议新增以下表结构来支持该功能：

* **`quiz_record`** **(测验记录表)**

  * 存储一次测验的元数据（用户ID、合集ID、分数、生成时间）。

* **`quiz_question`** **(题目表)**

  * 存储具体的题目内容（关联 `quiz_record`）。

  * 字段包括：`question_text`, `options_json` (JSON存储选项), `correct_answer`, `explanation`, `related_analysis_id` (关联原始分析结果，便于溯源)。

***

## 3. 开发实施规划

1. **后端开发**：

   * 创建 `QuizController`, `QuizService`, `QuizRepository`。

   * 集成 LLM 服务，编写专门用于生成测验的 Prompt。

   * 实现 JSON 解析逻辑，确保 AI 返回的数据能稳定存入数据库。
2. **前端开发**：

   * 改造 `CollectionDetailPage.vue`，对接真实 API。

   * 优化答题交互体验（加载动画、结果结算页面）。

***

## 4. 测试验证策略

1. **数据模拟 (Mockaroo)**：

   * 生成 1000+ 条 `quiz_question` 模拟数据，覆盖不同编程语言和难度。

   * 模拟用户的答题行为数据 (`quiz_record`) 用于压力测试。
2. **自动化测试**：

   * **JUnit**: 测试 Prompt 生成逻辑和 JSON 解析的容错性。

   * **Jest**: 测试前端答题组件的状态流转（从加载->答题->显示解析->结算）。
3. **性能测试**:

   * 测试高并发下生成测验（LLM 延迟处理）和提交答案的性能。
