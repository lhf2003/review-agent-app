# 前端项目文档

## 项目概述

**Review Agent** 是一个基于 Vue 3 + Vite 的代码审查/分析助手前端应用，提供用户认证、数据可视化、分析和集合管理功能。

### 技术栈

- **框架**: Vue 3.5.24 (Composition API + `<script setup>`)
- **构建工具**: Vite 7.2.4
- **UI 库**: Element Plus 2.11.9
- **状态管理**: Pinia 3.0.4
- **路由**: Vue Router 4.6.3
- **图表**: ECharts 5.6.0 + echarts-wordcloud 2.1.0
- **Markdown 渲染**: markdown-it 14.1.0 + highlight.js 11.11.1
- **动画**: motion-v 1.9.0
- **安全**: DOMPurify 3.3.0
- **密码加密**: node-forge 1.3.3 + Web Crypto API

### 3.1 Vue 组件规范

#### 3.1.1 组件结构

**所有组件使用 Composition API + `<script setup>`**：

```vue

// 2. 第三方库导入
import { ElMessage } from 'element-plus'
import MarkdownRenderer from './MarkdownRenderer.vue'

// 3. Props 定义（带类型验证）
const props = defineProps({
  items: {
    type: Array,
    default: () => []  // 数组/对象使用工厂函数
  },
  session: {
    type: Object,
    default: null     // 对象使用 null
  },
  content: {
    type: String,
    default: ''
  },
  sessionId: {
    type: [String, Number],  // 支持多类型
    required: true
  }
})

// 4. Events 定义
const emit = defineEmits(['itemSelected', 'update:visible'])

// 5. 响应式状态
const loading = ref(false)
const visible = ref(false)

// 6. 计算属性
const displayText = computed(() => ...)

// 7. 方法
function handleClick() { ... }

// 8. 生命周期
onMounted(() => { ... })
onUnmounted(() => { ... })
</script>

<template>
  <!-- 模板内容 -->
</template>

<style scoped>
/* 组件作用域样式 */
</style>
```

### 3.2 状态管理规范

#### 3.2.1 Pinia Store 定义

**Options API 风格** (auth.js):
```javascript
export const useAuthStore = defineStore('auth', {
  state: () => ({
    isAuthenticated: false,
    username: '',
    userId: null,
  }),
  actions: {
    async login(username, password) {
      const data = await api.login(username, password)
      if (data && data.code && data.code !== 0) {
        throw new Error(data.message || '登录错误')
      }

      const user = data.data || data
      this.isAuthenticated = true
      this.username = user?.username || ''
      this.userId = user?.id || null
      localStorage.setItem('auth', JSON.stringify({
        isAuthenticated: this.isAuthenticated,
        username: this.username,
        userId: this.userId
      }))
    },
    logout() {
      this.isAuthenticated = false
      this.username = ''
      this.userId = null
      localStorage.removeItem('auth')
      router.push('/login')
    },
    hydrate() {
      const raw = localStorage.getItem('auth')
      if (raw) {
        const obj = JSON.parse(raw)
        this.isAuthenticated = !!obj.isAuthenticated
        this.username = obj.username || ''
        this.userId = obj.userId ?? null
      }
    }
  },
})
```

**Setup Store 风格** (chat.js, theme.js):

#### 3.4.2 流式请求模式

```javascript
async function sendChat() {
  if (!auth.userId) {
    ElMessage.warning('请先登录')
    return
  }

  const text = chatInput.value.trim()
  if (!text) return

  chatStore.messages.push({ role: 'user', content: text })

  const handler = {
    onEvent: (chunk) => {
      const lastMsg = messages.value[messages.value.length - 1]
      if (!lastMsg || lastMsg.role !== 'assistant') {
        messages.value.push({ role: 'assistant', content: '' })
      }
      messages.value[messages.value.length - 1].content += chunk
    },
    onDone: () => {
      isStreaming.value = false
    },
    onError: (e) => {
      isStreaming.value = false
      ElMessage.error('聊天失败: ' + (e?.message || e))
    }
  }

  const streamCtl = api.chatStream(text, handler)
  // 需要时可取消: streamCtl.cancel()
}
```
